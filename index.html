Overview

What is the Medina Relay?

The Medina Agentic Relay assigns each phase of software development to the AI best suited for it. Built on obra/superpowers — a composable skills library — and extended with maestro-gemini for Gemini's build stage.

+
Claude Code
Ideate & Plan
Brainstorm, spec out, write the plan
brainstorming writing-plans worktrees
Claude runs the full superpowers design loop: collaborative brainstorming → approved spec → step-by-step implementation plan with exact file paths and test commands.
+
Gemini CLI
Build
Execute plan, commit code to repo
executing-plans /maestro:orchestrate
Gemini reads the self-contained plan and executes it. For complex parallel builds, maestro-gemini routes work to 22 specialist subagents. Simple sequential tasks use executing-plans.
+
Claude Code
Test & Verify
Review, debug, confirm quality
verification debugging code-review
Claude reads Gemini's commits, runs verification-before-completion, dispatches systematic-debugging if tests fail, and completes a code review before allowing a merge.
+
Either
Deploy
Merge, PR, or ship
finishing-branch
Either model can handle deployment. finishing-a-development-branch presents structured options: direct merge, pull request, or cleanup. Both Claude and Gemini support it.

◎ Skills-first: This framework builds Claude's reasoning quality before adding external integrations. MCP server connections (GitHub, Slack, databases) are Phase 2.

Hooks & Rules

Hookify rules are markdown files in ~/.claude/hookify.{name}.local.md that fire on events and show Claude a message or block an action.

Click any rule to expand its configuration.

🛑
long-run-drift-check — active in this setup
stop ›

Fires every time Claude is about to complete a session. Presents a 9-item checklist covering plan adherence, test status, build state, and relay handoff quality. Primary guard against silent failures on long autonomous runs.

name: long-run-drift-check enabled: true event: stop pattern: .*
⛔
block-dangerous-rm
bash ›

Hard blocks rm -rf and similar destructive shell patterns before they execute. The command will not run.

event: bash pattern: rm\s+-rf action: block
⚠️
console-log-warning
file ›

Warns Claude when writing console.log() to a source file. Allows the write but explains why debug logs should not ship to production.

event: file pattern: console\.log\(
🔐
sensitive-files-warning
file ›

Warns when editing .env files or credential files. Reminds Claude to verify .gitignore and avoid committing secrets.

event: file conditions: - field: file_path operator: regex_match pattern: \.env$|credentials

Architecture

Relay Architecture

The spec and implementation plan are the API between models. Claude writes them with enough precision that Gemini can execute without any context from the planning conversation.

Handoff Rules

RuleReason
Mark parallelism explicitlyGemini's subagent scheduler routes to specialists — it needs clear task boundaries. Claude's Task tool spawns dynamically; Gemini cannot match this exactly.
Self-contained task descriptionsEach plan task must be understandable with zero context from the planning conversation. Claude has that context; Gemini will not.
Reference outcomes, not tool namesGemini's tools differ from Claude's. Write "read the config file" not "use the Read tool".
Complex builds stay on ClaudeWhen a build requires dynamic subagent dispatch across many files, Claude's subagent-driven-development skill is more reliable than Gemini's specialist routing.
